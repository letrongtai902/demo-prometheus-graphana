What is Prometheus?

Open-Source Monitoring

  • Collects numeric metrics from applications
  • Stores time-series data
  • Powerful query language (PromQL)
  • Pull-based: scrapes targets on a schedule

What It Tracks

  • Counters — things that only go up
    (total requests, total errors)
  • Gauges — values that go up & down
    (active users, memory usage)
  • Histograms — distributions
    (response time percentiles)

Think of Prometheus as your application's vital signs monitor — constantly measuring health.

What is Grafana?

Visualization Platform

  • Turns raw metrics into dashboards
  • Charts, gauges, tables, heatmaps
  • Real-time, auto-refreshing views
  • Connects to Prometheus (and 50+ sources)

Alerting Engine

  • Define conditions on any metric
  • Automatic notification when thresholds are crossed
  • Routes to Email, Slack, PagerDuty, Teams
  • Alert states: Normal → Firing

Grafana is your control room — see everything at a glance and get alerted automatically.

Alerting: Automated Detection

Grafana evaluates alert rules on a schedule and transitions between states:

Normal
All clear — no issues
→
Pending
Condition met, waiting
→
Firing
Alert! Take action

Our Alert Rule

  • Condition: Any 5xx errors in the last minute
  • Evaluation: Every 10 seconds
  • Severity: Critical
  • Action: Notify team immediately

Demo Walkthrough Live

1. Before the Incident

  • Show HTTP Overview dashboard
  • Point out normal request rates
  • Show alert state: Normal
  • Open localhost:3000/alerting

2. Trigger the Incident

  • Run: dotnet run --project src/ErrorTrigger
  • Watch console: 500 responses
  • Switch to Grafana

3. Observe Detection

  • Error Rate by Endpoint spikes
  • Status Code pie shows 500 slice
  • Errors by Endpoint table fills
  • Alert: Normal → Firing

4. Resolution

  • Stop ErrorTrigger (Ctrl+C)
  • Wait ~1 minute
  • Error rate drops to zero
  • Alert: Firing → Normal

Key Takeaways

1.  Metrics beat logs for real-time monitoring — structured numbers are faster to query than text logs.

2.  Automate detection, don't rely on humans — alert rules catch issues in seconds, not hours.

3.  Monitor at every layer — HTTP + Business + System metrics give complete visibility.

4.  Easy to get started — open-source, one-command Docker setup, production-ready.
